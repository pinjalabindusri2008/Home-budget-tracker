# Home Budget Tracker

## Project Overview
Home Budget Tracker is a web-based application developed to manage and analyze personal income and expenses. It helps users record transactions, set monthly budgets, and understand their spending patterns.

## Technologies Used
- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS
- **Database:** MySQL
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib

## Features
- Dashboard to view financial summaries.
- Add and manage income and expense transactions.
- Categorize transactions.
- Set and monitor monthly budgets.
- View transaction history.
- Analyze expenses using charts.
- Compare monthly income and expenses.

## Database
The project uses MySQL to store transaction details, categories, and monthly budget information.

## Project Structure
- `Backend/` – Python backend and analysis files.
- `home_budget/` – Budget analysis and visualization scripts.
- `template/` – HTML templates.
- `static/` – CSS and static resources.

## Project Objective
The main objective is to help users manage their household finances, monitor expenses, and make better budgeting decisions.
